# Design mockups

Three versions of the Sirena HR screens (mobile app + web admin), exported from the design canvases.
Each folder has one `.dc.html` file per screen plus `canvas.json` (the canvas layout).

| Folder | Version | Live canvas |
|---|---|---|
| `v1-original/` | First pass (teal, plain) | https://claude.ai/artifact/EwQFEsFmU5BvbxR2tQryGN |
| `v2-playful/` | Playful and rich, Sirena 7-colour palette | https://claude.ai/artifact/QMFUSdfFMJkvpokmyPcDUT |
| `v3-minimal/` | Minimal: Sirena red, black, white, one grey (used by the app) | https://claude.ai/artifact/5USTqiTFskZqaLse5cATw3 |

Files starting with `W` are web screens; the rest are mobile screens.
The `.dc.html` files need the design canvas runtime to render, so open the live canvas links to view them.
